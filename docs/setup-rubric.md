# AI Development Setup Standards

The 14 parameters this repo is audited against in `docs/setup-audit.md`. Score each 0–2 with evidence (file paths or command output). Security-critical rows need command evidence.

| Parameter                | Security critical | What to check                                                                                                                                                                                                                                                                                                                                                                                                                                  | Where to look                                                                                                                                                       |
| ------------------------ | ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Instructions & Memory    | No                | Committed agent instruction file exists for every AI tool used; one source of truth across tools (AGENTS.md imported/symlinked); at or under ~200 lines; exact build/test/lint/typecheck commands that actually run; no stale paths; no conflicting rules; path-scoped rules in monorepos; personal files gitignored; no secrets                                                                                                               | CLAUDE.md, AGENTS.md, .claude/rules/, .cursor/rules/*.mdc, .github/copilot-instructions.md, .windsurf/rules/; wc -l; git log on these files                         |

| Subagents & Roles        | No                | Each custom agent has one purpose, explicit minimal tools list (read-only for reviewers/researchers), return format and length limit, deliberate model choice; an independent verifier/reviewer agent exists; agents reading web/issue content cannot also write, run shell or push; parallel agents isolated in worktrees                                                                                                                     | .claude/agents/*.md, .github/agents/, Codex config multi-agent settings                                                                                             |
